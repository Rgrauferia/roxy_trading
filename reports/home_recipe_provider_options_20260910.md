# Roxy: proveedores para 500 recetas reales

**Revisión de páginas oficiales: 10-09-2026. No se contrató, pagó ni activó ninguna API.** Cantidad anunciada por proveedor ≠ recetas revisadas individualmente por Roxy. Ninguna opción demuestra por sí sola 500 recetas completas, fotos correctas y cero errores.

## Fuentes públicas y editoriales revisadas

- **Food Hero / Oregon State**: la fuente describe pruebas de sabor, apariencia y textura, revisiones posteriores y seguimiento por educadores. Sus criterios incluyen medidas/tamaños de envase, utensilios, seguridad, fotos profesionales y español. Es la mejor vía de colaboración educativa encontrada; no se verificó una API, una licencia comercial general ni un inventario de 500. Pedir permiso de reutilización in-app, imágenes, traducción/narración y suministro estructurado; no descargar masivamente. [Proceso editorial](https://foodhero.org/about-food-hero), [criterios](https://foodhero.org/sites/foodhero-prod/files/health-tools/RecipeGuidelines_111020_v9.pdf), [guía de imágenes/licencias](https://foodhero.org/sites/foodhero-prod/files/health-tools/VideoTips_102620_2.pdf).
- **USDA**: Data.gov identifica **My Cookbook** como CC0, pero la distribución es un enlace antiguo y no se comprobó un archivo vigente con 500 recetas/fotos. Las páginas directas de MyPlate/recetas devolvieron 403; no se eludió. No asumir que todo material aportado por terceros es federal o revisado: la propia galería FNS advierte que no revisa exhaustivamente las contribuciones. [Metadatos oficiales](https://catalog.data.gov/dataset/my-cookbook), [galería FNS](https://www.fns.usda.gov/node/21701).
- **Michigan State Extension**: recetas públicas con cantidades/pasos, pero copyright universitario; no se encontró licencia masiva comercial/API ni cobertura confirmada de 500. Solicitar permiso de textos y fotos a cada titular. [Catálogo oficial](https://www.canr.msu.edu/extension-recipes/), [política MSU](https://innovationcenter.msu.edu/tech-transfer-commercialization/faculty-researchers/msu-copyright-policy/).
- **Tasty**: no se comprobó API pública autorizada; usar contacto comercial de BuzzFeed, no asumir autorización por un revendedor. [Ruta oficial](https://advertise.buzzfeed.com/tasty).
- **Otra vía editorial**: People Inc. anuncia miles de recetas con método/fotos, pruebas de cocina, API y caché permitida; también español. **Precio por cotización**, no confirmado económico. Puede encajar mejor que una API colaborativa si la prioridad es contenido ensayado. [Licencias de Allrecipes, EatingWell y otras marcas](https://peopleinccontentlicensing.com/content-types/recipes/).

## Propuesta de ejecución

Preparar TheMealDB como primera activación **sin pago**: abrir su página oficial de API y revisar el checkout enlazado, resolver moneda/tier comercial y derechos pendientes. Guardar la clave únicamente en servidor. Auditar primero 25 fichas diversas y después las 500 individualmente: pares ingrediente/cantidad, pasos íntegros, raciones, unidades/envases, cocción, foto propia del plato, derechos y origen. Si el proveedor no cubre suficientes fichas válidas, no completar huecos con IA ni anunciar 500; negociar contenido editorial con Food Hero/People Inc. o evaluar Plus. Roxy podrá narrar fielmente lo aprobado, no inventar pasos. Ninguna de estas APIs humanas autoriza trasladar recetas a mascotas.
