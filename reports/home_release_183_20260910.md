## Correcciones de código

- Entrada de despensa sin descartar campos, límites explícitos, comillas
  compatibles, coma/punto decimal, mensaje accesible y protección de doble envío.
- API valida todo el lote antes de reemplazar/mezclar; rechaza cantidades
  inválidas, unidades numéricas y filas mal formadas sin perder el inventario.
- Nexo y Comercio fallan de forma cerrada cuando su JSON es ilegible/corrupto
  o desaparece después de inicializar. Los GET que recuerdan miembros/precios
  ya no convierten esos casos en archivos vacíos. Atomicidad, fsync,0600,
  locks y503 sin rutas internas. No hay evidencia de corrupción real actual.
- Radar libera MapLibre, RAF, timers y solicitudes al ocultarse/salir; sólo
  reanuda dentro de identidad/permisos válidos. Respeta pausa manual y frescura.
  Respuestas de clima antiguas no reemplazan datos de un nuevo miembro.
- Docker incluye defaults persistentes para memoria, presupuesto y calendariosync;
  coinciden con YAML/runtime previamente comprobado. No Blueprint ni cambios de pago.
- Extractor Wikibooksv5 conserva referencias/notas/métodos alternativos. Offline,
